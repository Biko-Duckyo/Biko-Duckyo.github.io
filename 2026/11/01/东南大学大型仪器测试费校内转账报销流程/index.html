东南大学 · 大型仪器测试费校内转账报销流程（智能报销线上办理）

发表于2026-11-01|更新于2026-11-16|PhD之路

先确认系统适用范围

2026-11-16 复核：官方仍可查到 2025 年线下转账说明。2026 年线上试运行通知已检索到，但正文访问超时；下方线上步骤保留为操作笔记，须与当前系统及部门答复核对，不能推定全部场景已取消线下办理。

本页据《智能报销-大型仪器测试费校内转账操作流程》（系统截图流程）整理，并补充东南大学实验室与设备管理处、大仪共享系统、财务处智能报销手册等公开官方口径。本页为个人办事参考，字段默认值、项目号与审批状态以办理系统当前显示和本校区财务室答复为准。

先记住这条主线：两个系统、六步走完全线上

① 大仪系统发起「分析测试费转账申请单」（选实验记录提交）
        → 约 1 小时同步到财务系统
② 财务智能报销 → 选「校内转账-大型仪器测试费」
③ 填内转信息（事由 / 转账类型 / 转入项目号 / 金额）
④ 填转出经费项目、报销校区（多项目走费用分摊）
⑤ 辅助证据绑定本人名下申请单（未绑定无法提交）
⑥ 提交申请 → 负责人线上审批 → 直接进财务制单（委托打印·零投递）

旧稿记录了线上办理的试运行路径。是否适用线上免打印流程，应先核对当前系统通知；不能据此推定旧线下流程已在所有场景停用。

到账跟进：原笔记记录了试运行通知中的办理时限，本次未完整读取原文，不作时限承诺。提交后请在两个系统分别跟进实际审批、凭证和到账状态。

两个系统的分工

系统入口 / 责任部门在本流程中的职责
① 大型仪器管理系统
（大仪共享系统）		 实验室与设备管理处
dxyq.seu.edu.cn		 按实验记录发起「分析测试费转账申请单」，生成可被财务系统绑定的申请单号；服务对象与办理方式以当前系统权限和通知为准
② 智能报销平台 财务处综合信息门户
cwc.seu.edu.cn（PC / 微信手机端）		 申请报销 →「校内转账-大型仪器测试费」（试运行）：填报转账信息、选转出项目、绑定辅助证据、提交审批与制单

⚠️ 身份一致硬约束：智能报销的报销人必须等于大仪系统发起申请的本人；非申请用户在财务系统看不到该申请单，辅助证据列表也只显示申请人名下的分析测试费转账申请单。

Phase 01 / 发起侧 · 大仪系统

01

先在大型仪器管理系统操作

发起分析测试费转账申请单

  • 进入【个人账户信息】→【我要充值 / 我要转账】→ 选择【分析测试费转账申请单】。
  • 选择需缴费的实验记录，核对金额后提交，系统生成申请单号（示例单号形如 269348、269503）。
  • 提交后申请单同步财务系统约需 1 小时；在此期间登录财务系统取不到单，属正常同步延迟，稍后再办第 02 步。
申请单与后续绑定的对应关系
大仪申请单示例金额（截图记录）用途
申请单 2693482549.78 元在智能报销「辅助证据」中勾选绑定
申请单 26950318151.35 元同上；金额须与所绑实验记录一致

单号与金额仅为系统截图示例，办理时以本人名下实际申请单为准。

Phase 02 / 报销侧 · 智能报销平台

第 02–06 步在财务综合信息门户 → 智能报销平台内连续完成；草稿状态不冻结项目金额，可随时撤改。

02

同步完成后 · 进入智能报销

选择「校内转账-大型仪器测试费」业务类型

  • 财务处综合信息门户 →【智能报销】→【申请报销】→ 选择「校内转账-大型仪器测试费」（试运行新增业务）。
  • 确认当前登录报销人 = 大仪发起人本人；换人或代填将导致无单可绑。
  • 可先在草稿中填好再提交；草稿不冻结对应项目金额，可撤销修改。
03

填写转账信息（表单第一段）

内转信息：事由、类型、转入项目号与金额

转账事由最多 100 个汉字，简明写明测试内容（如「XX 样品 XX 仪器测试费」）。
转账类型选择「大型仪器分析测试费」（支出）。先选转账类型，再选转入项目。
转入项目号接收测试费的校内账户，表单默认 1160739030（以系统当前默认值为准；列表为空时可手动输入指定项目号）。
转入金额与第 05 步绑定的大仪申请单金额对应，不可随意填写。
提示：若转入项目下拉为空，先确认已选转账类型，再用手动输入项目号的方式补填。
04

下一步 · 经费与校区信息

选择转出经费项目与报销校区，多项目走费用分摊

  • 选择转出经费项目（本人名下有余额的项目），并选择报销校区（系统示例：四牌楼；其他校区按实际填写）。
  • 多个经费项目共同承担时，把项目选择模式切到「多项目」，使用【费用分摊】按比例拆分金额。
  • 可用「余额为 0」过滤，避免选中无余额项目；确需使用他人项目时，填写项目代码 + 负责人姓名后添加。
05

辅助证据栏 · 关键卡点

绑定本人名下的大仪转账申请单

  • 在「辅助证据」栏点击绑定，弹窗中勾选本人名下对应编号申请单 → 确认。
  • 未绑定时表单出现红字错误「尚未绑定校内转账」，无法提交；绑定后显示「已经绑定 / 共 1 笔」。
  • 列表口径：仅显示申请人名下的分析测试费转账申请单；查不到单时先回到第 01 步核对发起人身份与同步时间。
06

核对无误后提交

提交申请 → 负责人线上审批 → 直接制单（零投递）

  • 点击【提交申请】；提交后系统冻结对应项目报销金额。
  • 按适用流程完成项目负责人审批，再跟进财务制单；是否免打印和免投递，以系统提示及经办要求为准。
  • 「是否委托财务打印」选「是」：预约单待线上签批完成后直接进入物流等待入账，实现预约零投递、师生少跑路。
  • 审批被拒绝时，按审批意见修改后重新提交；可在「我的业务 → 审批中 / 已审批」跟踪状态。

常见卡点自查

卡点现象原因与处理
进财务系统取不到申请单大仪提交后约 1 小时才同步；稍候刷新，勿重复发起。
辅助证据列表无单可选报销人与大仪发起人不一致；须本人账号办理。
红字「尚未绑定校内转账」未绑定申请单；回到第 05 步弹窗勾选确认。
无法提交、提示项目为空 / 未选校区补齐转出经费项目与报销校区后再提交。
选中项目但金额不可用转出项目余额为 0；切换有余额项目或走多项目分摊。
金额校验不通过填报金额须与绑定的实验记录（申请单）金额一致。

报销单三段结构（截图对照）

分段主要字段要点
① 基本信息 报销人 / 实际报销人 / 联系电话 / 申请日期 / 经费项目 / 摘要 / 报销校区 / 是否委托财务打印 报销人须与发起人一致；委托打印选「是」。
② 转账信息 转账事由 / 转出项目 / 转入项目 / 转账类型（大型仪器分析测试费-支出）/ 转账金额；按钮【填写转账信息】【费用分摊】 先类型后项目；转入项目默认 1160739030；多项目用分摊。
③ 辅助证据 证据类型（校内转账-报销项等）/ 关联描述（共 N 笔）/ 提示说明（尚未绑定 → 已经绑定）/ 是否有相关业务 绑定本人名下申请单后才可提交。

截图中示例报销单号（如 5387274、5334733）与脱敏转出项目号仅供熟悉界面使用，办理时以本人实际单号为准。

智能报销平台通用规则（适用于校内转账与日常报销）

单据状态流转
状态含义与操作
草稿已编辑未提交，不冻结项目金额，可撤销重填或修改。
审批中已提交并冻结对应项目金额；项目负责人线上给出同意 / 拒绝及审批意见。
已审批显示「已预约待投递」或「已分配，等待制单」；可查看明细、审批日志，支持打印 / 撤销。
委托打印类（零投递）助研学金、校内转账等业务签批后直接进入物流等待入账，是否需要打印递交，以适用流程和办理部门要求为准。
审批责任（手册口径）
  • 经办人（报销人）对报销事项的真实性、合法性、合规性负直接责任。
  • 项目负责人对签批开支的真实性、合法性、合规性、相关性与效益性负直接责任。
  • 内控要求：项目负责人与经办人为同一人时，须由课题组或院系其他人员协同签字审批。
平台入口与常用模块
  • 入口：东南大学财务处综合信息门户 → 智能报销平台（PC 端 / 微信手机端）。
  • 申请报销：待报销票据 + 日常报销、国内差旅、酬金申报、助研学金、校内转账（试运行）等业务类型。
  • 常用维护：校外人员、常用联系人、常用项目号、酬金常用名单；可先维护减少重复填写。
  • 我的业务：草稿 / 审批中 / 已审批 / 全部报销单；待我处理：待我审批 / 我已审批（负责人视角）。
历史校区财务规则参考（点击展开）

以下阈值来自旧稿整理的苏州研究院指南，未核实可通用于其他校区、经费或当前年度。大仪转账不应直接套用采购报销规则，请向本校区财务确认。

历史校区采购与报销口径摘录

以下为财务公开指南中的共性口径整理，跨校区、跨经费科目细则以本校区财务室和当前财务手册为准；校内测试费转账本身不附发票，主要适用「项目合规、金额对应、线上留痕」要求，票据类红线供其他日常报销对照。
事项口径要点
报销时限当年开具的发票原则上在当年 12 月 30 日前完成报销。
票据要求合法有效票据，抬头为东南大学；按预约项顺序整理、同类归集、保持清晰不污损。
明细清单单张 / 连号 / 短期内同一商家累计 ≥ 1000 元，须附明细清单（发票已列明明细的除外）。
支付凭证非财政专项经费，单张（连号）≥ 2000 元须附支付记录或对公汇款，且支付方与开票方一致。
合同门槛单笔 ≥ 5 万元经济业务须签订书面合同；严禁拆分发票规避合同签订与采购招标。
一次性报销同一笔经济业务原则上一次性报完，不得分拆开票规避结算管理。
资产建账单价 > 1000 元的设备类须建立资产，不得按办公用品报销。
材料入库化学试剂不论金额附采购清单；实验材料 ≥ 1000 元附《材料验收入库单》并签字盖章。

退单高频原因：≥1000 元无明细清单；办公用品与专用材料混淆；个人 / 家庭生活用品；应建资产未建账；入库单未盖章；支付记录与开票单位不一致。

本篇是 CONF-01 参会笔记 的续篇，整理第二批 20 张现场照片（编号 21–40），主题从脑血管影像临床病例延伸到代谢磁共振、梯度硬件与脑磁图。会议背景与第一批归纳见上篇。

现场照片为会场大屏翻拍，部分数字、项目号与论文卷期被遮挡；幻灯数据以现场 PPT 为准，公开背景资料列于文末。本文为学习归纳，不构成临床或工程方案建议。

五、卒中影像：临床病例与基层智能救治

5.1 黑血血栓成像：明确诊断脑静脉窦血栓

黑血血栓成像（接上篇 DANTE 黑血血栓直接成像）在病例上的直观表现：上下两排矢状位 T1 加权像，上排为右侧、下排为左侧，红色箭头标示静脉窦内血栓高信号；右侧可见明确血栓显影，左侧对照。

5.2 典型漏诊病例：精准诊断头颈交界区管壁病变

病例：33 岁男性，言语不清 2 小时，DWI 提示新发脑梗。

  • 常规影像：头部、颈部血管均判为正常，病变漏诊；
  • 管壁成像：确诊头颈交界区管壁病变（黄色箭头），属于管腔成像容易漏掉的交界部位管壁病变。

5.3 影像智能体：助力基层卒中快速救治

eStroke 国家溶栓取栓影像数据平台（现场幻灯统计，时点以平台实时数据为准）：

  • 平台诊断总量 27,382 例；卒中救治患者量 9,179 例；eStroke 成员医院 / 卒中中心 200 家；
  • CT 血管评估量约 15,750 例次，MR 血管评估量约 9,240 例次。

AI 分析流程：原始影像 → UNet 分割缺血半暗带与核心梗死区；并完成溶栓出血风险评估、微出血检测。

分级救治链路：基层医院（医生、患者、影像检查、静脉溶栓）→ 5G 传输 → 基于 4D 时空网络模型的影像智能分析平台（快速多模影像评估、卒中分析报告、救治推荐）→ 远程指导 → 高级 / 国家级卒中中心、区域联盟、医疗集团 → 动脉取栓。

背景补充：eStroke 由首都医科大学宣武医院互联网医疗诊治技术国家工程实验室联合东软医疗研发，面向缺血半暗带、脑微出血、侧支循环的多模态定量评价；其 AI 辅助分析软件纳入《急性脑梗死缺血半暗带临床评估和治疗中国专家共识》推荐。

本批脑血管影像幻灯片桌牌为杨旗教授（首都医科大学附属北京朝阳医院副院长、医学影像中心主任）团队：长期构建脑血管病磁共振精准诊断体系，包括高分辨快速全脑动脉壁成像、静脉黑血血栓直接成像（诊断准确率约 97%）与头颈一体化接收线圈，与上篇第三部分的方法创新一一对应。

六、低场闭环康复与纳米氧化铁血池对比剂

6.1 国家重点研发计划：低场磁共振引导个体化闭环康复系统

系统构成（幻灯示意）：

  • 便携式低场床旁磁共振：床旁影像评估；
  • 超声神经调控操作台：调控参数与刺激执行；
  • 数字孪生脑仿真平台：脑状态仿真与方案推演；
  • 边缘计算服务器：本地闭环计算与数据存储。

项目号现场被遮挡（20…17800），未予补全。

6.2 新型纳米氧化铁全身血管成像对比剂

目标：牵头中国纳米氧化铁对比剂 I 期临床试验，创立磁共振血管成像新技术，获得国人首幅动静脉分离全身血管图像。

  • 左侧为国家药监局药物临床试验批准通知书；
  • 右侧脑血管图像对比：3T 体素 0.5×0.5×2.0 mm vs 7T 体素 0.3×0.3×1.2 mm；
  • 临床试验登记号现场可辨认 NCT06010537、NCT06051565（部分遮挡，以注册平台为准）。

续页为红色脑血管网络三维重建与 7T 高分辨脑血管像（0.3×0.3×1.2 mm）。

背景补充：纳米氧化铁（USPIO，如 ferumoxytol）是血池型对比剂，血浆半衰期长、血管内停留稳定，不经肾脏清除，适合肾功能不全患者；稳态分布下可在一次检查中区分动脉与静脉，为钆对比剂之外的 MRA 备选路线。

七、睡眠剥夺与脑功能连接

7.1 慢性睡眠限制后的持续性认知缺损

研究标题：Persistent cognitive deficits after chronic sleep restriction。

实验方案（n = 62）：

阶段 安排
Baseline Sleep B1、B2，10h 卧床时间（TIB）
Chronic Sleep Restriction Period 1 SR1–SR5，4h TIB
Dose Response Intervention（DRI） 0h / 2h / 4h / 6h / 8h / 10h / 12h TIB 剂量梯度
Chronic Sleep Restriction Period 2 SR6–SR10，4h TIB
Recovery Sleep R1、R2，10h TIB

另设 10h TIB 对照组（n = 8）。结局指标包括 PVT 警觉任务 lapse 次数（标准化）与总睡眠时间 TST(h)；散点图按不同恢复条件对比睡眠限制第 1–5 天与第 6–10 天的表现。

7.2 静息态 BOLD：突显网络功能连接

Resting BOLD: salience network connectivity。

  • 对比状态：TSD-BL（睡眠剥夺基线）与 CD1-BL；
  • 涉及脑区：Putamen（壳核）、aINS（前岛叶）、IFG（额下回）、Parietal Lobe、MFC；Seed 位于突显网络核心区；
  • 相关分析：dACC–Putamen 连接 r = 0.50，p = 0.003；dACC–aINS 连接 r = 0.41，p = 0.015；自变量为膳食脂肪供能比（% kcal from fat）；
  • 右侧柱状图对比睡眠剥夺组与对照组在基线、整夜清醒、TSD、CD1 阶段的热量摄入与蛋白质 / 碳水化合物 / 脂肪供能比例。

引用：Fang et al., Scientific Reports 2015。

八、高磁场梯度：连接组成像的硬件基础

8.1 为什么需要高磁场梯度

解决思路：

  • 弥散加权系数（↑）：低梯度下神经纤维交叉结构无法区分，高梯度可准确区分交叉走行；
  • 回波时间 TE（↓）：T2 弛豫指数衰减是信号主要损耗源，提高梯度强度可缩短弥散编码时间、压短 TE，减少信号衰减；
  • 磁场梯度强度 G（↑）：贯穿弥散编码波形与梯度系统设计。

核心成果：人脑连接图谱 3T 磁共振仪（Connectome scanner），磁场梯度强度 G = 300 mT/m，7 倍于行业标准；梯度系统由 X / Y / Z 方向三组功率放大器驱动。

8.2 全球磁场梯度强度发展趋势

背景补充：常规临床 3T 全身梯度多在 80 mT/m、200 T/m/s 量级；300 mT/m 级梯度最早为人类连接组计划（HCP）在 MGH 定制，主要服务于弥散纤维束追踪与组织微观结构成像——更高梯度可在更短 TE 内完成弥散编码，提升 SNR 并探测更受限的微观水扩散。

九、CEST 免标记代谢磁共振成像

本部分幻灯片桌牌为宋小磊团队（清华大学生物医学工程学院），围绕化学交换饱和转移（CEST）从腹部瓶颈、序列编码、谱图解析到 AI 图 / 谱增强的完整链条展开。

9.1 长期瓶颈与 CEST 探测机制

长期瓶颈：极弱信号（低于水的 0.1%）+ 有限采样（呼吸运动），导致代谢成像「慢且糊」。

探测机制——化学交换饱和转移（CEST）：利用低浓度代谢分子与水的动态交换—累积，实现信号放大。

  • 相比 MRS 放大 >100 倍，可探测约 sub-mM 级浓度；
  • 具备频率特异性 / 选择性，可按化学位移区分代谢物。

原创方法链（软件驱动成像）：

环节 贡献
采集序列 提出空-频协同编解码理论方法，突破腹部高清成像禁区
图谱解析 构建超分超谱 CEST 分析体系，破解 3T 多代谢物谱峰重叠与定量难题
多核拓展 拓展 CEST 至磷核、氟核，实现高灵敏成像与动态代谢通量评估

技术平台目标：建立「免标记」人体糖、脂、蛋白高清 3D 成像体系，实现磁共振从「看结构」向「看代谢」跨越，支撑疾病筛查、精准分型与疗效早评，可重复评估代谢时空变化。

9.2 从动物到临床：免标记高时空分辨代谢成像

小动物 MRI（9.4T）：Nat. Commun. 2015（一作），「免标记」探测小鼠肿瘤糖蛋白；获 Hopkins Research Highlight，并由 FOX News、Telegraph、Science Daily 等报道。

Towards clinic（糖 / 蛋白 / 脂类）：

  • 采集耗时挑战：谱域空域同时编码、高效采样轨迹、双 B1 交换率对比成像；
  • 图 / 谱质控挑战：图域 K 空间联合重建、自由呼吸腹部成像、水预饱和快速精准。

人体多色 CEST（3T）：Nat. Commun. 2026（通讯作者），呼吸冻结 CEST 成像精准识别肝癌复发灶；SSE-CEST 饱和场强 0.7 μT；区分复发灶（高代谢）与坏死灶（低代谢）；对照钆造影剂、游离蛋白、糖原、脂类信号。

9.3 代表性成果：单次屏气全肝全谱 CEST

  • 可重复性：单屏气图像无伪影，可重复性从 60% 提升到 97%；采集 11 条编码线，重建 120 个 Δω 频偏；附相关系数矩阵与归一化均方误差矩阵；成像对比包括 ST(1.2 / 3.5 / −3.5 ppm) 与 APTw。
  • 糖耐实验（口服）肝脏动态糖代谢：Baseline、9 min、21 min、51 min 葡萄糖加权信号动态变化。
  • 多器官多代谢物：肝、脾、胰腺；蛋白、肌酸、糖（原）；对比饭后 2 小时与整晚禁食两种状态。
  • 成果：Nature Communications 2026（唯一通讯）。

9.4 免标记 SSE-CEST 与 FDG-PET 对比

三层面（Slice 13/41、15/41、26/41）并列 T1w、Amide CEST（0.7 μT）、Glucose ST（2 μT）与 FDG-PET；右侧标注：超快单屏气扫描，人体腹部多器官高分辨代谢成像。

背景补充：SSE（spatial-spectral encoding，空间-频谱编码）通过饱和梯度施加 z-ω 编码模式，结合 CEST 谱低秩性的数据驱动空谱重建，在单次屏气内完成全肝 3D 全谱扫描；重复扫描相关系数约 0.95，可区分肿瘤活性灶与治疗后坏死，与 PET、钆对比剂诊断高度吻合。

9.5 3T 谱分析：频率重要性排序 + 背景拟合

3T CEST-MRI 挑战：谱拓宽、峰「不见」、多代谢物成像难；9.4T 下可见清晰谱峰，3T 下标签信号仍然真实，但逐峰拟合（fitting each peak）不再可行。

左路：基于体素分类的频率重要性特征提取——传统 MRI「定位」+ 代谢物频率「定性」；输入 T2w、Gd-T1w、APTw，输出蛋白、糖、水、脂类、半固态大分子的频率重要性标签。

右路：拟合背景参考谱后求差——降维拟合「背景谱」+ 保真代谢频偏「求差」；展示游离蛋白与脂类（髓鞘）分布图，以及蛋白、Cr、脂类拟合曲线。

引用：NMR Biomed 2023 / MRM；MRM 202? / QIMS 2023（卷期以原文为准）。

9.6 AI 图增强与 3T–9.4T 谱增强网络

左：可临床落地的多对比超分辨-图增强

  • 痛点：代谢图像「低分辨」长期不足；
  • 思路：以自身结构像或高分辨关键频偏像为参考，不牺牲 SNR 与扫描时间，满足个性化、精准诊断；5 分钟采集即可达到传统 20 分钟采集的图质；
  • 网络：LR Encoder / Ref Encoder、隐式特征采样（IFS）与隐式图像生成（IIG）、交叉注意力特征融合、Decoder；ICG + 微调实现跨场景泛化，N > 3 后收敛；
  • 发表：IEEE TMI 2025、Medical Image Analysis 2024、IEEE TMI 2024。

右：3T–9.4T 映射超分辨-谱增强网络

  • 痛点：低场谱拓宽 / 峰难辨、特异性差；
  • 思路：基于模型训练与实采微调，建立 3T–9.4T 谱映射网络，从 3T 实采 Z 谱「预测」超高场更细分 Z 谱；
  • 流程：Bloch-McConnell 模型生成配对 Z 谱 → B0 校正模块 → 特征蒸馏模块 → 缩放归一化 → SVD 截断模块 → 特征向量与 SVD 反演；
  • 发表：NMR Biomed 2024。

十、脑磁图：无创全脑探测与无线穿戴溯源

10.1 脑磁图无创探测全脑神经活动

脑磁图（MEG）以毫秒级时间分辨率、毫米级空间分辨率同时记录全脑神经活动，广泛用于脑认知机制、脑神经与精神疾病研究，并支撑神经解码脑机接口应用。

幻灯散点图按对数坐标比较各模态的空间分辨率（layer / column / region / mm）与时间分辨率（ms / second / minute / hour）：EEG、MEG、nIRS 偏无创侧，sEEG、ECoG 偏侵入侧；fMRI 空间分辨高但时间分辨慢；SPECT、PET 时间分辨最慢。右上为 δ、θ、α、β、γ 频段功率谱与时频活动图。

引用：Baillet, Nature Neuroscience；Rempe et al., PNAS（年份以原文为准）。

10.2 无线穿戴式脑磁图溯源成像

攻克无线通讯磁兼容技术难题，在国际上首次实现自由运动状态下的无线脑磁信号采集与溯源成像。

硬件分层：头盔外壳（Helmet Covering）、泡沫头盔（Foam Helmet）、传感器阵列（Sensor Array）；采集模块、控制电路、采集电路、数据 BLE、触发 BLE、非磁性锂电池；整机约 238 × 331 mm。

实验环境：MSR 磁屏蔽室、主动屏蔽线圈、动作捕捉相机、传感器内嵌头盔、无线控制系统、远端计算机主机；输出自由运动轨迹（Trajectory）与 DICS 溯源定位脑图。

引用：NeuroImage 2024；Cheng & He et al., under review。

背景补充：穿戴式 MEG 多基于光泵磁力计（OPM），2018 年 Boto 等在 Nature 报道可佩戴、可自由活动的头盔式 MEG；国内中科院生物物理研究所王帆团队研制了穿戴式原子磁力计脑磁图，并配套方舱式高性能磁屏蔽室，推动 MEG 从固定扫描走向移动捕捉。

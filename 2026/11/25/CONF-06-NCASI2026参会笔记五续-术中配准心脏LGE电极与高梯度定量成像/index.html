二十二、RT-MRI 术中实时非刚性配准（南开大学）

22.1 三网络框架：超分、刚性配准与图像融合

幻灯标题：RT-MRI 术中实时非刚性配准——基于频域感知和状态空间模型的配准网络（南开大学）。

整套方法由三个网络模块组成：

  • (a) 超分辨率网络：输入 1×80×80 LR-IMRI 切片，经 Conv/BN/ReLU 编码器与 FCN 全连接层重建高分辨切片；
  • (b) 刚性配准 / 切片匹配网络：输入 390×256×256 HR-PMRI 容积与 1×256×256 HR-IMRI 切片，在笛卡尔空间经刚性变换与重采样，孪生网络（Conv/pool/Conv/pool/Flatten，输出 h1/h2）完成切片匹配；
  • (c) 图像融合网络：I_tar / I_ref（1×256×256 HR-IMRI / HR-PMRI 切片）经权重共享特征提取网络与图像融合层，输出 I_fuse，最终重建 390×256×256 HR-IMRI 容积，并完成穿刺针分割与针尖位置提取；总损失记为 ℒ_all(·)。

幻灯底部指出既有配准方法存在高频细节信息丢失、特征交互不足以及缺少针体跟踪的问题（部分文字被遮挡），据此提出配准融合方法与高效特征模块。

22.2 交叉 Mamba 交互与频域感知选择模块

图像融合网络结构：I_tar/I_ref 经 Patch 增强 → 剪枝卷积 → 浅层融合器 → 浅层特征 A/B → CMIM 交叉 Mamba 融合器 → 深层特征 A/B → Patch 增强 → FASM 频域融合 → 解码器 → I_fuse。

交叉 Mamba 交互模块（CMIM）：引入状态空间模型，在降低模型计算复杂度的同时兼顾全局结构建模与局部细节表达，实现术中与术前特征之间的有效信息交互；通道含归一化、MLP、Conv、SiLU、SSM，以及 DW Conv 与 FFN 输出。

频域感知选择模块（FASM）：输入经线性映射与 DWT 层分解为 LL/HL/LH/HH 子带，各子带经融合模块（Conv/GELU/Conv）得到描述特征；通道注意力（Avg pool、FC pool、Softmax）对原始子带与新子带分别融合，再经 IDWT 层与融合模块、Sigmoid 输出 F_fuse。模块对不同频率成分选择性提取，强化高频细节信息，缓解融合过程中边缘模糊和纹理丢失，使穿刺针及解剖结构（尾部文字被遮挡）得到保留。

23.2 5T 心脏成像：优势与挑战

优势：更高的信噪比，提升图像质量。

挑战一：心电门控的准确性

  • 改进滤波电路和算法：降低梯度干扰信号，减少杂波；
  • 最优心电信号选择：自动选择心电信号最优通道做 R 波触发；
  • 优化 R 波检测算法：孔径内外及多状态心电学习，实时掌握心电状态。

挑战二：心脏匀场效果不佳

  • 预校正时心脏分割：精准提升感兴趣区域匀场效果；
  • B0/B1 分别匀场：保证图像质量；
  • 控制生理运动：（多次屏气，具体次数被遮挡）。

二十四、脑机接口电极：共生融合挑战与微创植入路线

24.1 总结：涌现效应与电极发展方向

幻灯以「总结」页提出五点判断（中科院院徽）：

  1. 当电极通道足够多、脑机信息交互足够多时，预期出现脑机集成的涌现效应；
  2. 脑机涌现将彻底改变人类生活的方方面面；
  3. 脑机接口系统不像硅基 AI 大模型可快速追赶，开发需要多年技术积累；
  4. 脑机接口电极向着更加柔软、动态、高密度方向发展；
  5. 适应大脑动态特性的电极系统依然有待研究；其长期生物相容性机制依然需要阐明（第 5 点首词被遮挡）。

24.2 共生融合脑机接口系统的瓶颈

关键瓶颈：界面机制不清、主动融合不足，导致长期功能衰退。

  • 长期植入慢性免疫排异：引用美国科学院院士、神经接口电极国际领军者、中科院外籍院士 Charles M. Lieber 综述——Novel electrode technologies for neural recordings，Nature Reviews Materials 20, 330–345 (2019)；摘要指出现有技术虽可记录低频局部场电位与单单位信号，但仍面临长期复杂度、有害慢性免疫反应与长期稳定性问题；幻灯另注低多路复用度、稳定性等待突破。
  • 主动融合不足：右侧神经元示意与 Na⁺/K⁺/Ca²⁺ 离子标注，归纳三条隔阂：①（被遮挡）、②没有互动、③深度隔阂。

  • 解决策略：超薄电极加工；动态结构重构与自适应展开电极策略。

25.2 ²H 代谢与超极化 ¹³C 成像互补

²H 代谢可以与超极化 ¹³C 代谢成像完美互补：

  • 超极化 ¹³C 观测快速生理代谢（1 min）；²H 观测慢速生理代谢（1 hour）；
  • 左侧：1 scan 单谱与 >200,000 scan（65 h）累计谱对比；Polarization / T1 decay 水桶示意；T1 时间短，可大量累计提升信噪比，且几乎没有背景信号；
  • 累计次数对照表：¹H 弛豫 ~3 s、1 min 内累计 20 次；¹³C ~0.3 s、200 次；²H 累计 2 次（具体弛豫时间被遮挡）；
  • 右侧：²H 是 ¹H 的稳定同位素，无放射性；²H 代分子不会改变代谢途径；FDG 与 Glucose(d66) 经 transporter/hexokinase 进入糖酵解（→lactate）、糖脂代谢/fatty acids、TCA（→glutamate/glutamine）；
  • 谱图对比：¹³C 谱含 [4-¹³C]-Glu、[4-¹³C]Gln、[3-¹³C]Lac；²H 谱含 water、glucose、Glx、lactate。

25.3 MRS 研究面临的两大挑战

挑战 1：代谢物谱图拥挤

  • 代谢物成分种类繁多且复杂，每种均含多条谱峰且有复杂 J 偶合裂分结构；
  • 氢核谱图频率范围有限：临床 3.0T 中，10 ppm 仅 1270 Hz 频率范围；
  • 谱线标注：Cr、Glx、mI、Cho、NAA、Cr、NAA Glx、Lip。

挑战 2：非常强背景峰（水和脂肪）

  • 人体内水和代谢物含量比值约 10000 倍；幻灯类比为珠穆朗玛峰 8848.86 m 与 3 岁小孩高度（~0.9 m）的比值；
  • 谱线标注：H₂O（5.0 ppm）、GSH（3.0 ppm）、GABA、Lac（~2.0 ppm）。

底部结论：强信号掩盖微量代谢物信号，代谢物种类繁多、化学位移重叠，导致灵敏度低、难以准确分辨与定量（作者署名被遮挡）。

25.4 纯化学位移 NMR：消除 J 偶合裂分

纯化学位移 NMR 机制：消除 J 偶合裂分，提高谱图分辨率。

  • 纯化学位移技术（同核宽带去偶）通过消除 J 偶合裂分效应，将多重谱峰转化为单重峰，简化谱图，提高谱图分辨率，克服复杂样品体系谱峰拥挤甚至重叠问题；
  • 流程：Conventional ¹H NMR 经 PSYCHE（RF、Gx 脉冲）得到 Pure shift ¹H NMR；
  • 两种主要宽带去偶模块为 ZS 和 PSYCHE，可采用伪二维采样或实时采样，结合数据拼接后实现纯化学位移 NMR；
  • 实现路径：90° 脉冲、t1/2 延迟、ZS/PSYCHE 模块、t1/2 → 2D Acquisition → 1D FID Reconstruction；引用 Zangger et al., Prog. Nucl. Magn. Reson.（卷期被遮挡）。

二十六、柔性 ECL 离子凝胶：Ru/DBAE/DES

第 23 分会（电化学分析）报告 Performance of Ru/DBAE/DES ECL Ionogel。

  • 制备流程（A）：DES + gelatin + Ru(bpy)₃²⁺ + DBAE，75 °C 搅拌 1 h → 4 °C 冷却 8 h → 形成网络凝胶；分子标注 Ru(bpy)₃²⁺、DBAE、gelatin chain；
  • 组分与作用：
    • Gelatin：生物相容聚合物，促进与 DES 的氢键与静电相互作用；
    • Ru(bpy)₃²⁺：ECL 发光体；
    • DBAE：环境友好共反应剂，性能优于 TPA；
    • Synthesis：加热 → 澄清溶液 → 冷却 → 固体 ECL 凝胶；简单、可重复、适合规模化生产；
  • 展示特性：B 红色凝胶圆盘；C 条状凝胶支架；D Press/Relax 压缩回弹；E 在 glass、stainless steel、PET plate、paper 基底上粘贴；F Cooling/Heating 温变可逆。

结论：ECL ionogel 具备柔性器件构建的独特性质——良好发光能力、可拉伸性、弹性与粘附性（部分形容词被遮挡）。

二十七、高梯度系统上的定量成像（浙江大学）

27.1 CSF Flow Imaging：低 VENC PC-MRI 与 SCIMI

qMRI on High Gradient Systems — CSF Flow Imaging（浙江大学生物医学工程与仪器科学学院）。

  • 高梯度支持相位对比（PC）MRI 中的低 VENC 编码，编码速度公式：$v_{enc} = \dfrac{\pi}{\gamma G \tau^2}$；
  • 左：4D flow MRI——血液 VENC = 120 cm/s，脑脊液 VENC = 1.0 cm/s；四条曲线分别为 Left MCA M1（r_max = -0.89，lag = 18 ms）、Left ACA A1（-0.82，-98 ms）、Left PCA P2（-0.88，45 ms）、Left MCA M2（-0.92，120 ms），CBF rate 与 CSF rate 随心动周期（插值后）变化；@MAGNUS (2MV)，300 mT/m；引用 Fluids and Barriers of the CNS；
  • 右：SCIMI（Simultaneous Coherent/Incoherent Motion Imaging），速度分辨率 <0.2 cm/s；RL / AP / SI Motion 三组脑图；@MAGNUS；Jansen et al., Interface 2020（卷期被遮挡）。

27.2 SANDI：胞体与神经突密度成像

Diffusion encoding on High Gradient Systems — Soma and Neurite Density Imaging (SANDI)。

  • 最大 b = 6000 s/mm²，δ/Δ = 6/13 ms，2 mm 各向同性分辨率；
  • 神经突内信号分数 f_in 在 Connectome 2.0 扫描仪上显著高于 Connectome 1.0（后者 δ/Δ = 8/19 ms）；
  • 处理流水线：2 mm iso DWI 经超分辨率至 1 mm iso DWI；解剖 MRI 分割 → 上/颗粒下层（Supra/Infraglanular layers）、21 个层片表面（5% 间隔）、WM/Pial 表面；SANDI f_is / f_in 与组织学细胞构筑、髓鞘构筑做皮层深度依赖对比；
  • 右侧对比：C2.0 SANDI f_is 皮层表面从 Overall、Pial surface（Depth 0%）到 WM surface（100%）分层图，与 BigBrain Merker staining 对照；下方为散点图与染色强度曲线；Connectome 2.0（500 mT/m，600 T/m/s）；Communications Biology, 2025。

Butterfly 标签外挂使用手册

发表于2026-10-06|更新于2026-11-16|Hexo 教程
|总字数:1.8k|阅读时长:5分钟|浏览量:

标签外挂把 Markdown 中的内容关系变得更清楚：重点提示、并列方案、可收起的补充说明。这里按本站实际支持的写法整理，每项先看效果，再复制源码。

适用范围：本站当前 Hexo 8 + Butterfly 5.7 配置，复核于 2026-11-16。 标签外挂不是标准 Markdown，也不是文章 front-matter 中的分类标签。换主题或移除插件后，需要重新确认支持情况。

一、先按内容选组件

内容 建议写法 使用边界
前提、概念纠错、关键提醒 Note 提示块 少量使用，避免整篇都变成提示
可以选择其一的并列方案 Tabs 不把必须依次完成的步骤拆开隐藏
长配置、推导、历史背景 hideToggle 主要结论和限制保持可见
普通任务清单 Markdown 复选框 不等于可跨设备保存的待办系统
相关资料入口 普通链接或 btn 按钮只用于明确的下一步

四、折叠：补充内容按需阅读

实际效果

展开查看完整检查步骤
  1. 确认正在访问的域名、端口和文章版本。
  2. 查看控制台或构建日志中的具体错误。
  3. 只在明确需要时清理缓存，避免同时改变多个条件。

折叠标题应说明里面是什么，例如“完整配置”“公式推导”或“历史方案”。不要只写“更多”。

复制源码

hideToggle 来自主题。扩展插件还提供 folding，但写法与样式不同；一篇文章选一种折叠风格即可。重要的单位、实验条件、口令配置前提和结论不要折叠隐藏。

五、清单、按键和文字强调

大多数文字样式直接用 Markdown 或 HTML，无需额外插件。

  • 标出已完成的检查
  • 列出下一步要做的事情

按键效果：Ctrl + K。任务勾选的展示不代表自动保存；学校办事清单等页面的状态保存是单独实现的功能。

六、按钮与资料卡

一个明确的下一步

浏览全部文章

参数依次是地址、文字、图标和样式。本站主题注册的是 btn，不是 button。

资料卡什么时候用

写法 内容来源 适用情况
Markdown 链接 作者自己描述 正文引用与系列导航，最轻量
link 手写标题、站名、地址 需要固定措辞的资料入口
ogcard 抓取外链元信息，支持手动覆盖 少量需要封面与摘要的扩展阅读

后两者是本站自研标签，不能当作所有 Butterfly 网站的内置能力。ogcard 可能在构建时访问外部网站；单纯提供参考资料时，普通链接通常已经足够。

七、图库、时间线和图表

这些组件只在内容确实需要时使用，图片还应配替代文字、图注与来源。

时间线写法

它用于按时间组织内容，不必把普通步骤列表改成时间线。

图库写法

示例地址是占位符，使用前替换为实际文件。不要用缺失图片充当效果展示。

Mermaid 要同时检查渲染配置。 本站虽注册了相关标签，但主题的 mermaid.enable 目前为 false。复制标签不会自动得到流程图；现有 SVG 可继续使用，启用新渲染器前应另行验证。

八、旧速查表需要纠正的写法

旧写法 当前替代
check Markdown 清单，或扩展插件的 checkbox
bold Markdown 的双星号加粗
underline 有必要时使用 HTML 的 u 元素
delete Markdown 删除线或 HTML 的 del 元素
kb HTML 的 kbd 元素
button 主题的 btn

这六个旧标签名在本站当前注册表中不存在，不应作为可复制的可用示例。要展示标签源码，把它放进代码块，避免正文解析时把示例当作真正组件。

参考与后续检查

  • Hexo 标签插件文档：解释标签插件与文章标签的区别。
  • Butterfly 标签外挂文档：主题组件的语法参照。
  • 本站的实际注册以已安装主题、扩展插件和根目录 scripts/ 为准。

更新后检查：复制代码仍是字面源码，Tabs 能切换，折叠能开合，手机没有页面横向溢出，换页返回后交互仍可用。

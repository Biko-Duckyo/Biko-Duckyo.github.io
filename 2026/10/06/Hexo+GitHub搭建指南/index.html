Hexo + GitHub 搭建个人博客完整指南

发表于2026-10-06|更新于2026-10-06|Hexo 教程
|总字数:508|阅读时长:2分钟|浏览量:

环境准备

Node.js

推荐使用 nvs（Node Version Switcher）管理版本：

或直接去 nodejs.org 下载 LTS 安装包。

Git

去 git-scm.com 下载安装包，一路下一步。
安装后右键菜单会出现 “Git Bash Here”。

安装 Hexo

初始化博客

浏览器打开 http://localhost:4000 看到默认主题即成功。

部署到 GitHub

1. 新建仓库

仓库名必须是 用户名.github.io，例如 QINchao998314.github.io。

2. 配置 SSH 密钥

复制公钥 → GitHub → Settings → SSH and GPG keys → New SSH key。

测试连接：

3. 配置 Git 用户

4. 安装部署插件

5. 修改 _config.yml

6. 部署命令

访问 https://用户名.github.io 即可。

常用命令速查

命令 作用
hexo new "文章标题" 新建文章
hexo new page "页面名" 新建独立页面
hexo g 生成静态文件
hexo s 本地预览
hexo d 部署
hexo clean 清理 public 和 cache

常见问题

Q: 4000 端口被占用？

Q: 部署后样式丢失？
检查 _config.yml 的 url 和 root 配置。

Q: 文章中文标题 URL 乱码？
安装 hexo-abbrlink 生成唯一链接，见 Butterfly 配置篇。
